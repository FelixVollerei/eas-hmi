# Reproducible examples

`room.eas` is a small completed project with promotion, two moves and undo/redo navigation.
Copy the directory before experimenting. Every reference is relative; no original developer
path is needed. Inspect, export and replay it with an installed EAS Visual + Inkscape.

The generator is `scripts/demo_visual.py`. Run from a clone:

```sh
python scripts/demo_visual.py --output build/my-visual-demo
```

The output path must not exist. `--case structural`, `--case generative` or `--case undo` runs
a subset. Structural/undo use original synthetic artwork generated by Python. The generative
demo uses a **real cached model crop from the prior POC**, not a new model call or a mock smile.
Its exact input crop is bundled and checked against the new project's baseline pixels.

Output includes saved scene directories, original/edited PNG, pure vector SVG, masks, pixel
diffs, untouched-region diffs, full comparisons, local enlargements, JSON metrics and a CLI
timing journal. The journal counts process invocations; it is not an Agent token benchmark.
Random revision IDs/timestamps differ each run; expected rendered pixels and hashes match.

See [artwork attribution](../../THIRD_PARTY.md). The character input was already composited
onto white before this release; that bundled input is preserved exactly in each new project.
When recording a video, show the mask, raw provider context changes, untouched count, and
undo hash match. Keep "cached model output" and "manual mask" visible.
